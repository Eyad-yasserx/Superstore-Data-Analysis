# Superstore Data Cleaning & Exploratory Data Analysis

## Project Overview

This project analyzes Superstore sales data using Python to identify patterns, trends, and business insights.

## Objectives

* Clean and prepare the dataset.
* Handle duplicate records and transform data.
* Perform Exploratory Data Analysis (EDA).
* Analyze sales and profit performance.
* Visualize findings using charts.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Key Deliverables

* Data cleaning and preparation.
* Exploratory data analysis.
* Data visualizations.
* Summary of key findings.
